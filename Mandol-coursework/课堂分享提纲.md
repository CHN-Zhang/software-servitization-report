# 第一次课堂分享提纲

可以按下面顺序准备约 8 页 PPT，具体按课堂规定的时间调整。

1. **我准备做什么**：长期对话里的重复记忆很多，想改进 Mandol 的 L1 合并，兼顾信息和来源。
2. **系统大致怎么组织**：用报告里的对象图说明 Unit、Space、Map 和 Graph 的关系。
3. **本任务在哪个流程里**：L0 → L1 → 去重 → L2 → 写入；标出准备改的位置。
4. **原来怎样去重**：给出 `merged_from` 保留第一项的源码片段，说明去重需要启用开关。
5. **做了什么实验**：先做15组固定返回值回归检查，再做48组分层样例（16开发、32评测），最后使用qwen3.6-flash完成64次真实请求。重点讲来源问题、条件句失败和22次格式偏差，不能只展示较好的分数。
6. **准备怎样改**：相同主体和类型下，等价或字面包含才合并，来源取并集，不确定就保留。
7. **目前做到哪里**：受控实验、离线对照、真实模型组件实验和独立原型已完成；标注还未独立人工复核，完整接入和真实检索评测未完成。
8. **后续安排**：先接入原流程，再比较原策略与新策略，检查误合并、来源、L2 和检索效果。

可能被问到的问题：

- 为什么不直接让模型重新总结？目前先减少生成错误，先做保守代表选择。
- 100% 覆盖是不是说明已经成功？不是。初次受控检查不能代表实际效果；真实回答全部回放中原型事实保留为93.8%，还有条件范围误合并。
- 是否能节省大量内存？目前没有测，而且 L0、索引和图仍可能存在，不能提前保证。
- 与原系统的区别是什么？重点是对建议做检查、选择覆盖信息更全的代表，并汇总来源。
